# Checklist

## 后端基础
- [x] Rust 项目可编译通过（`cargo build` 无错误）
- [x] 后端启动时正确加载 `config/models.yaml` 中的模型配置
- [x] 后端启动时从环境变量 `LLM_API_KEY_{PROVIDER}` 读取 API Key
- [x] 后端启动时输出日志（包含监听端口、已加载模型数量）
- [x] API Key 不在日志中完整输出（仅前 4 位 + 掩码）

## 模型管理 API
- [x] `GET /api/models` 返回模型列表，包含 id/name/provider/enabled/status 字段
- [x] `PUT /api/models/{id}` 成功更新模型 enabled 状态并返回确认
- [x] `PUT /api/models/{id}` 对不存在的模型 ID 返回 404

## SSE 流式对话
- [x] `GET /api/chat/stream` 消息为空时返回 400 错误
- [x] `GET /api/chat/stream` 消息超过 4000 字符时返回 400 错误
- [x] 后端并发向所有已启用模型发送请求（非串行）
- [x] SSE 正确推送 `chunk` 事件（含 model 和 content 字段）
- [x] SSE 正确推送 `done` 事件（含 model 和完整 content）
- [x] SSE 正确推送 `error` 事件（含 model、error.code、error.userMessage）
- [x] 单个模型失败不影响其他模型正常返回
- [x] 模型超时（60 秒）后推送 `error` 事件，不阻塞其他模型
- [x] 禁用模型不参与对话请求
