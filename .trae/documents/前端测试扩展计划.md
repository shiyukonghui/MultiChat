---

## 注意事项

1. 所有测试使用中文注释
2. Mock 数据应与真实数据结构一致
3. 测试应覆盖正常流程和异常流程
4. 组件测试应关注用户交互而非实现细节
5. API 测试应覆盖各种 HTTP 状态码响应
6. SSE 流式测试需要模拟 EventSource
