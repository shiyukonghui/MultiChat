# 模型热重载功能

## 问题分析

当前添加模型后的数据流：

```
前端添加模型 → POST /api/models → 后端写入内存 + YAML ✅
                  ↓
            ModelConfigPanel 重新 fetchModels() ✅
                  ↓
            侧边栏 ModelSidebar 不更新 ❌
```

侧边栏（`modelStatuses`）在 `chatReducer` 中通过 `INIT_MODELS` action 初始化，这个 action 在 SSE 连接建立时触发。添加模型后没有机制通知 reducer 更新模型列表。

## 解决方案

### 核心思路

在 `ChatState` 中添加一个**模型列表**字段，并提供公开方法让 `ModelConfigPanel` 能触发更新。添加模型后两步走：
1. `ModelConfigPanel` 重新加载模型列表 ✅（已有）
2. 通知 `useChatStream` 更新内部 `modelStatuses`

### 实现方案：添加 `refreshModels` 方法

**方案选型**：由于 `modelStatuses` 在 `chatReducer` 中管理，最简单的方案是暴露一个 `refreshModels` 方法，调用后前端重新请求 `/api/models`，更新 reducer 中的模型列表。

### 修改文件

| 步骤 | 文件 | 改动 |
|------|------|------|
| 1 | `types/index.ts` | 新增 `REFRESH_MODELS` action 类型 |
| 2 | `utils/chatReducer.ts` | 处理 `REFRESH_MODELS` action：只更新 `modelStatuses` 中的模型 ID 列表，不重置内容 |
| 3 | `hooks/useChatStream.ts` | 新增 `refreshModels` 方法，调用 `/api/models` 获取已启用模型并 dispatch |
| 4 | `pages/ModelConfigPanel.tsx` | 添加模型/启用禁用模型后，调用 `onModelsChange` 回调通知父组件 |
| 5 | `App.tsx` | 为 `ModelConfigPanel` 传入 `onModelsChange` 回调，触发 `refreshModels` |

### REFRESH_MODELS 逻辑说明

```typescript
case 'REFRESH_MODELS': {
  const modelIds = action.payload; // 从 API 获取的已启用模型 ID
  const newStatuses = { ...state.modelStatuses };

  // 1. 新增模型：添加为 pending 状态
  modelIds.forEach(id => {
    if (!newStatuses[id]) {
      newStatuses[id] = { id, name: id, provider: '', content: '', status: 'pending' };
    }
  });

  // 2. 已移除的模型：从状态中删除（保留原有内容的模型不移除，仅移除空的）
  Object.keys(newStatuses).forEach(id => {
    if (!modelIds.includes(id)) {
      const status = newStatuses[id];
      // 只移除从未有内容的模型（pending 状态），有内容的保留
      if (status.status === 'pending' && !status.content) {
        delete newStatuses[id];
      }
    }
  });

  return { ...state, modelStatuses: newStatuses };
}
```

### 流程图

```
添加模型 → POST /api/models → 后端保存 ✅
    ↓
ModelConfigPanel 本地列表更新 + 调用 onModelsChange()
    ↓
App.tsx 收到回调 → 调用 useChatStream.refreshModels()
    ↓
refreshModels → GET /api/models → 获取已启用模型列表
    ↓
dispatch REFRESH_MODELS → modelStatuses 更新
    ↓
ModelSidebar 自动重渲染 ✅
```

### 注意

- `refreshModels` 只处理**已启用**的模型，禁用的不显示在侧边栏
- 正在流式回复中的模型不会被刷新影响（保留原有 content 和状态）
- 只添加新增的模型和清理已移除的空状态模型
