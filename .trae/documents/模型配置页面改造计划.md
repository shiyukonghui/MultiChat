# 模型配置页面改造计划

## 一、目标设计分析

从参考图片识别出的关键信息：

### 1. 页面结构
- **标题**: "添加模型"（右上角有关闭按钮）
- **模式切换**: "模型服务商" / "自定义配置" Tab切换
- **表单主体**: 多个配置输入项
- **底部操作**: "添加模型" 按钮

### 2. 表单字段清单

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| API 格式 | 下拉框 | ✓ | 默认"OpenAI Chat Completions 格式" |
| 自定义请求地址 | 输入框+开关 | ✓ | 占位符"e.g. https://api.openai.com/v1"，带"完整URL"开关 |
| 模型 ID | 输入框 | ✓ | 带"多模态"开关 |
| API 密钥 | 密码输入框 | ✓ | 占位符"输入 API 密钥" |
| 模型系列 | 下拉框 | × | 说明：针对特定模型系列优化了 Prompt 和超参 |
| 模型展示名称 | 输入框(限32字) | × | 占位符"请输入模型展示名称"，带字数计数(0/32) |
| 上下文窗口-输入 | 数字输入框 | × | 默认值184000 |
| 上下文窗口-输出 | 数字输入框 | × | 默认值16000 |
| 工具调用轮次 | 数字输入框 | × | 默认值200 |

### 3. UI细节

**提示信息卡片**：
- 蓝色背景带 info 图标
- 提示内容："请填写兼容 OpenAI API 的服务端点地址，不要以斜杠结尾。/chat/completions 将会被补充到你填写的地址末尾。"

**开关样式**：
- "完整URL"开关：灰色关闭，绿色开启
- "多模态"开关：灰色关闭，绿色开启

**高级配置**：
- 可折叠展开/收起
- 展开图标为向下箭头

## 三、改造计划

### 阶段一：数据模型扩展

**任务**：扩展 ModelConfig 类型定义，添加新字段

```typescript
export interface ModelConfig {
  // 原有字段
  id: string;
  name: string;
  provider: string;
  enabled: boolean;
  status: 'available' | 'unavailable' | 'unknown';
  reason?: string;
  
  // 新增字段
  apiFormat: 'openai-chat-completions' | string;  // API 格式
  apiEndpoint: string;                             // API 端点地址
  apiKey?: string;                                 // API 密钥（敏感信息）
  isMultimodal: boolean;                           // 是否支持多模态
  modelSeries?: string;                            // 模型系列，默认"默认"
  displayName?: string;                            // 展示名称，默认使用 id
  contextWindowInput?: number;                     // 上下文窗口-输入，默认184000
  contextWindowOutput?: number;                    // 上下文窗口-输出，默认16000
  toolCallRounds?: number;                         // 工具调用轮次，默认200
  useFullUrl: boolean;                             // 使用完整URL
}
```

### 阶段二：后端API扩展

**任务**：修改 Rust 后端，支持新的模型配置字段

1. 更新 `server/src/models/mod.rs` 中的模型结构
2. 更新 `server/config/models.yaml` 配置格式
3. 更新 `server/src/routes/models.rs` 路由处理
4. 添加敏感字段（apiKey）的安全处理（加密存储或不存储在配置文件）

### 阶段三：前端UI组件实现

**任务**：重新设计 ModelConfigPanel 组件

1. **布局改造**：
   - 从列表模式改为"卡片列表 + 添加弹窗"模式
   - 添加"添加模型"按钮
   - 每个模型卡片显示：模型名称、状态、编辑/删除按钮

2. **添加/编辑弹窗组件**（参考目标设计）：
   - 使用 MUI Dialog 组件
   - 集成所有表单字段
   - 实现 Tab 切换（模型服务商/自定义配置）
   - 实现高级配置的折叠展开
   - 表单验证

3. **表单组件清单**：
   - 分栏/Tab组件
   - Select下拉框（API格式、模型系列）
   - TextField输入框（带各种配置）
   - Switch开关（完整URL、多模态）
   - 可折叠面板（高级配置）
   - Alert提示框（API端点说明）

### 阶段四：样式与交互优化

1. 使用 MUI 组件库保持与现有项目一致
2. 实现表单验证逻辑
3. 添加操作反馈（Snackbar/Toast）
4. 移动端适配
